# Changelog

## [4.7.0] — 2026-03-09

### Added
- Sliding-window rate limits per API key, with `Retry-After` and a remaining
  allowance header on every 429.
- `GET /v2/search` now accepts `cursor` for stable pagination.

### Changed
- Connection pool sizing is now per-instance rather than global. This is the
  fix for the 12 February checkout incident.

### Deprecated
- `GET /v1/search`. Removal no earlier than 2026-09-01.

### Fixed
- A 500 when `limit` was zero rather than absent.
